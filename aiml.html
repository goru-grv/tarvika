Artificial Intelligence & Machine Learning

Study how data, algorithms and computing systems can support predictions, classification and other tasks—and how to evaluate their limits, risks and real-world usefulness.

Register your interest ↗All programs
What this field explores

Build intelligent systems with evidence and accountability.

AI is a broad field concerned with systems that perform tasks associated with perception, language, reasoning or decision support. Machine learning is one family of methods that uses data to fit models for defined tasks.

Learning this field involves more than using a model or tool: it includes framing a suitable problem, understanding data, setting up comparisons, examining failure cases and explaining where a system should not be used. Program format and technical depth depend on the specific TARVIKA offering.

Core lensData, algorithms, evaluation and application
Learning modeConcept study, experiments and documented projects
Responsible focusPrivacy, bias, robustness, safety and human oversight
Possible areas of study

Understand the full path from question to model.

Topics are indicative and may vary by course level, available tools and project scope.

01 / FOUNDATIONS

AI and machine learning concepts

Learn core terms, common task types and the difference between a problem, a method and a deployed system.

02 / DATA

Data preparation and exploration

Inspect data quality, represent information appropriately and document collection, permissions and limitations.

03 / METHODS

Models and learning methods

Explore suitable introductory approaches for classification, prediction, clustering or language tasks as appropriate to the course.

04 / EVALUATION

Testing, baselines and error analysis

Compare against baselines, choose metrics that match the goal and examine where and why a model fails.

05 / APPLICATION

From notebook to use case

Consider how outputs might fit a workflow, interface or decision process, including monitoring and human review.

06 / RESPONSIBILITY

Ethics, safety and limitations

Discuss privacy, bias, explainability, misuse, reliability and appropriate human oversight.

Research and project ideas

Test a specific claim instead of chasing a demo.

Example project directions are for learning and discussion; they are not claims of deployed systems or guaranteed outcomes.

PROJECT IDEA 01

Compare models on a defined dataset

Establish a baseline, select appropriate measures and document limitations and error patterns.

PROJECT IDEA 02

Responsible language-tool evaluation

Assess a bounded language task using safe, consented or public data and examine failure cases.

PROJECT IDEA 03

Human-in-the-loop prototype

Design a small decision-support concept that keeps user review and system uncertainty visible.

A possible learner roadmap

Learn the method, not just the model call.

Sequence and technical prerequisites are confirmed for each course format.

01 / FRAME

Define a task

State the question, intended user, constraints and what success would mean.

02 / PREPARE

Understand the data

Inspect sources, quality, permissions, representation and possible bias.

03 / EXPERIMENT

Build and compare

Test an appropriate baseline and method, then examine errors and trade-offs.

04 / COMMUNICATE

Explain limits

Present evidence, failure modes, risks and responsible next steps.

Fit and expectations

Curiosity, patience and careful testing.

Who may find it useful

Learners interested in AI, data and software applications. Maths, coding and data prerequisites vary; check the specific course description before enrolling.

What to bring

Willingness to work through examples, question assumptions, document experiments and discuss uncertainty.

What you may develop

Depending on course work: introductory data preparation, model evaluation, technical communication and a documented project.

What is not guaranteed

Production-ready AI systems, model accuracy, a job, placement, certification or university degree. TARVIKA does not award university degrees.

Do not upload personal, confidential or sensitive data to external tools. Any project using human data requires proper consent, permissions and applicable ethics review before work begins.
